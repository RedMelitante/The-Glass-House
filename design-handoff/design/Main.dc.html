Tokens and components for theghglass.com, built for Astro + Tailwind (ScrewFast / Preline as plumbing only). Every value below maps to a Tailwind class or a tailwind.config token.

Principles
  1. Photography leads. UI frames it, never competes.
  2. Crisp edges: 2px radius, 1px hairlines.
  3. Glass effects only where they earn it: the hero form and image captions.
  4. Estimate + phone are always one tap away.

Logo + brand colors are provisional until the logo file is supplied.
